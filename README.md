## GEMS ALT — упрощённый Match-3 на SDL3

## Управление
- ЛКМ: выбрать плитку; повторная ЛКМ по соседней плитке — обмен местами.
- Любая другая кнопка мыши — снять выделение.

## Правила и бонусы
- Совпадение 3+ по горизонтали/вертикали удаляется; столбцы над удалёнными клетками падают вниз, сверху добиваются случайные цвета из палитры.
- После каждого сдвига автоматически выполняется повторная проверка на новые совпадения.
- Бонус может выпасть с вероятностью 50% в окрестности радиуса 3 от любой удалённой клетки.
- Бонусы (отрабатывают автоматически):
  - Paint3 (синий маркер внутри клетки): перекрашивает целевую клетку в случайный цвет палитры и две случайные НЕ-соседние клетки в радиусе 2 — в исходный цвет клетки-источника.
  - Bomb5 (красный маркер): уничтожает 5 произвольных клеток, включая ту, куда попала (сдвиг столбцов вниз, добивка сверху).

## Сборка (CMake + FetchContent)
Требуется компилятор C++17 и доступ в интернет для подтягивания SDL3 (или используйте системный пакет, см. опцию ниже).

```bash
cmake -S "./alt" -B "./alt/build" -DCMAKE_BUILD_TYPE=Release
cmake --build "./alt/build" -j
```

Исполняемый файл: `alt/build/gems_alt`

## Запуск
```bash
cd "./alt/build"
./gems_alt
```

## Опции CMake
- `-DUSE_SYSTEM_SDL3=ON` — использовать установленный в системе SDL3 (через `find_package(SDL3 CONFIG REQUIRED)`) вместо FetchContent.

Примеры:
```bash
cmake -S ./alt -B ./alt/build -DCMAKE_BUILD_TYPE=Release -DUSE_SYSTEM_SDL3=ON
cmake --build ./alt/build -j
```

## Параметры поля (см. `include/Engine.hpp`)
- Размер окна: 800×600
- Размер клетки: 40×40
- Кол-во столбцов/строк: вычисляется из размеров окна и клетки
- Палитра: 6 предустановленных цветов
- Шанс спавна бонуса: 50%
- Радиус спавна бонуса: 3
