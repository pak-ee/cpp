# Minimal Arkanoid (C++20 + SFML)

Простая учебная реализация Арканоида для сдачи лабы. Без ассетов и шрифтов: всё рисуется примитивами SFML.

## Возможности (по условию)
- 1) Неразрушаемые блоки (серые)
- 2) Скрытые бонусы, падают вниз
- 3) Блоки-ускорители (оранжевые)
- 4) Многохп-блоки (голубые = 2 HP)
- 5) Бонусы: расширение/сжатие платформы, ускорение/замедление мяча, липкая платформа
- 6) Бонус: одноразовое «дно»
- 7) Бонус: случайный отскок (клавиша R тоже применяет)
- 8) Бонус: подвижный блок (бирюзовый), живёт до 3 ударов
- 9) Бонус: второй мяч (есть столкновения мяч‑мяч)

## Управление
- Влево/Вправо: движение платформы
- Пробел: запуск мяча
- R: применить «случайный отскок»
- Esc: выход

## Сборка (Linux/Fedora)
1) Установить SFML:
   ```bash
   sudo dnf install -y SFML-devel
   ```
2) Сборка и запуск:
   ```bash
   mkdir -p build && cd build
   cmake ..
   cmake --build . -j
   ./mini
   ```

## Обозначения цветов
- Платформа/мяч: белые (липкая платформа — жёлтая)
- Блоки:
  - Серый: неразрушаемый
  - Голубой: 2 HP
  - Зелёный: 1 HP
  - Оранжевый: ускоритель мяча
  - Бирюзовый (если появился во время игры): подвижный (бонус 8)
- Бонусы (круги):
  - Зелёный: расширить платформу
  - Красный: сжать платформу
  - Синий: замедлить мяч
  - Жёлто‑оранжевый: ускорить мяч
  - Бледно‑жёлтый: липкая платформа
  - Коричневый: одноразовое «дно»
  - Фиолетовый: случайный отскок
  - Бирюзовый: заспавнить подвижный блок
  - Розовый: второй мяч

Сборка (Fedora): sudo dnf install -y SFML-devel && mkdir build && cd build && cmake .. && cmake --build . -j && ./mini
Цвета и значения бонусов — см. minimal/README.md.
